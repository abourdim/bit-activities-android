# 🎯 Bit Activities — Android wrapper

Capacitor wrapper that packages the [bit-activities](https://github.com/abourdim/bit-activities) web app as an installable **Android APK**.

> أنشطة البِت · Bit Activities

Forty-eight guided activities for the BBC micro:bit, from first LED blink to BLE-driven robots and on-device AI. Trilingual EN/FR/AR interface, nine theme palettes, zero dependencies. Pair your micro:bit over Bluetooth and learn by doing.

## Quick start

```bash
./manage.sh    # auto-detects your OS, then opens the menu
```

Build, test on emulator, and prepare a Play Store release from a single guided menu. See [WORKSHOP.html](WORKSHOP.html) for the full step-by-step guide.

## Download the latest APK

[📦 v1.0-debug release](https://github.com/abourdim/bit-activities-android/releases/latest) · [![QR](releases/download-qr.svg)](https://github.com/abourdim/bit-activities-android/releases/latest)

Scan the QR with an Android phone, or `adb install -r bit-activities-v1.0-debug.apk`.

## Capabilities required at runtime

- Bluetooth Low Energy (Web Bluetooth → @capacitor-community/bluetooth-le)
